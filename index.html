Ajouter des résultats

Sur la page des résultats, sélectionne tout le bloc et copie-le, puis colle ici. Les deux présentations du site sont reconnues (avec la ligne « Pro League. Russie », ou sous le titre « Pro League ») ; seuls ces matchs sont retenus, « Pro League. Tchèquie » et les autres compétitions sont écartées. Un match déjà en base n'est pas ajouté deux fois. Le site affiche ses heures selon le pays de connexion (Paris, Europe de l'Est, Moscou ou Bakou) : la base est tenue en heure de Moscou et chaque collage est converti. Sans preuve suffisante, l'appli te demande de choisir.

Importer en un geste depuis Safari

Un raccourci iPhone « Importer vers H2H » s'ajoute au menu Partager de Safari. Il envoie tout le texte de la page de résultats ouverte à ton script Google. Le script garde les matchs de la Pro League russe, détecte le fuseau horaire, écarte les doublons et les écrit dans ta feuille. Une notification résume l'import. Ensuite, ouvre H2H : l'appli se met à jour seule.

Le raccourci ne lit que ce que la page affiche. Une catégorie repliée n'est pas envoyée.

Réglages de l'appli (une seule fois)
  1. Ouvre l'onglet Données, rubrique « Connexion à ta feuille Google ».
  2. Colle l'adresse du script (elle se termine par /exec) et ta clé secrète.
  3. Touche Enregistrer et tester. Le message « Connexion réussie » indique le nombre de matchs de la feuille.
Créer le raccourci (une seule fois)
  1. Autoriser les scripts. Réglages › Apps › Raccourcis › Avancé › activer « Autoriser l'exécution de scripts ».
  2. Créer le raccourci. Dans l'app Raccourcis, touche « + » et nomme-le « Importer vers H2H ».
  3. Action « Exécuter JavaScript sur la page web ». Remplace le code proposé par cette ligne :
    completion(document.body.innerText);
  4. Action « Obtenir le contenu de l'URL ». URL : l'adresse /exec du script. Méthode POST. Corps de la requête JSON avec trois champs texte : cle = ta clé, texte = la variable « Résultat JavaScript », fuseau = auto.
  5. Action « Obtenir la valeur du dictionnaire ». Clé message, dans « Contenu de l'URL ».
  6. Action « Afficher la notification ». Texte : « Valeur du dictionnaire ».
  7. Afficher dans le menu Partager. Dans les réglages du raccourci (icône i), active « Afficher dans la feuille de partage » et ne garde que « Pages web Safari ».
L'utiliser au quotidien
  1. Dans Safari, ouvre la page des résultats et déplie la catégorie Pro League (sans « Tchèquie »).
  2. Touche Partager, puis Importer vers H2H.
  3. Lis la notification : nombre de nouveaux matchs, fuseau détecté, rejets.
  4. Ouvre H2H. Si les chiffres n'ont pas changé, touche Actualiser dans l'onglet Données.

Alternative sans raccourci : colle le texte dans l'onglet Importer, vérifie le résumé, puis touche Enregistrer. Le script refait la même analyse.

En cas de souci
Notification « Clé refusée »
La clé du raccourci n'est pas identique à la propriété CLE du script. Recopie-la à l'identique.
« Aucun match Pro League Russie trouvé » ou compte à 0
La catégorie Pro League n'était sans doute pas ouverte sur le site. Ouvre-la et relance le raccourci.
Message « Fuseau horaire incertain »
Le site affiche ses heures selon le pays de ton VPN. Le script le reconnaît grâce aux matchs déjà en base, au planning des salles, puis à l'heure affichée en haut de la page. Sans preuve suffisante, il n'enregistre rien. Passe alors par l'onglet Importer et choisis le fuseau : en hiver, même heure que Paris = Paris, +1 h = Europe de l'Est, +2 h = Moscou, +3 h = Bakou.
Page Google ou message d'erreur au lieu de la notification
Le déploiement du script n'est pas ouvert à « Tout le monde », ou une ancienne version est encore déployée. Après toute modification du script : Déployer › Gérer les déploiements › Modifier › Nouvelle version.
L'appli affiche d'anciennes données
Elle montre sa copie locale quand le réseau manque. Touche Actualiser (ou Tout recharger) dans l'onglet Données.
Des matchs manquent
La page de résultats ne remonte sans doute pas loin dans le passé (non vérifié). Importe régulièrement, par exemple chaque soir.
Finales et matchs de 3e place depuis le 07/11/2026
Le site n'affiche plus la salle ni la phase des matchs. L'appli reconstitue les tournois à partir des joueurs : une poule, ce sont 4 ou 5 joueurs qui se rencontrent tous une fois. Une revanche entre deux joueurs de la poule, juste après, devient la finale (les 2 premiers) ou le match de 3e place (3e et 4e). Il peut rester de rares erreurs quand un match manque dans les données.
